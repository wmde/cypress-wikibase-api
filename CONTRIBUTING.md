# Contributing

## How to make a new Release

1. Update the version number in `package.json` (follow [Semantic Versioning](https://semver.org/)),
   then run `npm install` to update `package-lock.json`.
   This should happen in a separate commit,
   though you may include it in the same Pull Request as the feature/change motivating the release.
1. Merge the Pull Request with that commit.
1. Tag the commit with the new version number on master locally and push the tag to GitHub.
   A regular (not signed, not annotated) tag is good enough for now: <code>git tag v<var>1.2.3</var></code>
1. On GitHub, create a new "[Release](https://github.com/wmde/cypress-wikibase-api/releases)" for the tag with information on what changed.
   You can use the message generated by GitHub as a basis.
1. GitHub actions will push the new Release to [npm](https://www.npmjs.com/package/cypress-wikibase-api).
